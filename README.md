# SubmitGuard MVP

面向学生的作业提交前智能检查产品原型。当前版本覆盖 PRD 中的 P0 体验闭环：

- 粘贴作业要求并生成可编辑规则
- 确认、增删与修改规则
- 上传 PDF 并展示分阶段检查进度
- 查看必须修复、建议检查与已通过结果
- 演示安全自动修复、重新检查和报告导出

## 本地运行

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```

当前检查结果为前端演示数据；真实 PDF 解析、规则提取和文件修复接口预留给后续后端实现。若本机 pnpm 启用了严格的依赖构建审批，可先按提示批准 `esbuild`，或使用其他兼容的 Node 包管理器安装。
