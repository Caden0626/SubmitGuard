# SubmitGuard MVP

面向学生的作业提交前智能检查产品。当前版本覆盖 PRD 的核心体验闭环，并已接入第一阶段的真实 PDF 检查能力：

- 粘贴作业要求并通过确定性规则提取生成可编辑检查项
- 确认、增删与修改规则
- 在浏览器本地验证并解析文字型 PDF（文件不会上传服务器）
- 检查真实文件名、大小、页数、字数估算、必需章节、邮箱和 PDF 元数据
- 查看必须修复、建议检查与已通过结果，并导出可打印报告
- 保留演示文件入口，方便在没有测试 PDF 时体验完整流程

## 本地运行

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```

真实文件使用 PDF.js 在浏览器本地解析。当前仅支持单个、未加密且包含可提取文字的 PDF，最大 30 MB；扫描件 OCR、姓名识别、PDF 修改和自动修复仍留待后续阶段。演示文件继续使用预设结果。若本机 pnpm 启用了严格的依赖构建审批，可先按提示批准 `esbuild`。
